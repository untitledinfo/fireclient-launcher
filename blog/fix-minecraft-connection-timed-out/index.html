How to fix "Connection timed out" and "Failed to connect" in Minecraft

A checklist for "Connection timed out", "Connection refused" and "Failed to connect to the server" in Minecraft 1.21.1.

On this page
  1. If you are joining a server
  2. If you host the server
  3. Read the error text
  4. Get help

"Connection timed out" and "Failed to connect to the server" usually mean your game cannot reach the server, or the server cannot accept you. Start with the checks for players, then see the section for people who host.

If you are joining a server#

  1. Check the address and port. A typo is the most common cause. If the server uses a port other than 25565, add it after a colon.
  2. Check the version. Your game must match the server. For 1.21.1, use a 1.21.1 profile, and check the server's required version.
  3. Check that the server is online. Ask the owner, or check the server's website or Discord.
  4. Restart your router and PC. This clears many network glitches.
  5. Turn off VPN or proxy. Try again without them.
  6. Check Windows Firewall and security software. Make sure Java is allowed.
  7. Try another network. A phone hotspot shows whether your home network or school network is the problem.
  8. Check mods. A mod that changes networking can break joining. Test with a clean profile, as in the crash checklist.
  9. Check whitelist and bans. Some servers only accept listed players.

If you host the server#

  • Join localhost first. If that fails, the server is not running correctly.
  • Forward TCP 25565 to the PC, allow Java in the firewall, and check you are using your public IP address.
  • If your provider uses CGNAT, port forwarding cannot work.

The full steps are in the Paper server guide.

Read the error text#

"Connection refused" means something answered but did not accept, which often points to a wrong port or a server that is not running. "Timed out" means nothing answered, which often points to a firewall, router or wrong address.

Get help#

Ask in the FireClient Discord and share only the error text. Never post tokens, account files or your router login.
