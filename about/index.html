FireClient/About

About FireClient

FireClient is a free Minecraft Java launcher and Fabric in-game client for Windows, made by FirePDX and Sajjad Ahmed. It is in early access.

What FireClient is

One install gives you a Windows launcher that manages Minecraft versions, mods, worlds and resource packs, and an in-game client for Minecraft 1.21.1 on Fabric with a menu and a draggable HUD. It includes a Modrinth mod manager and can also launch other Vanilla, Fabric and Forge versions.

Is this the FireClient you are looking for?

Several unrelated projects use a similar name, including a FireClient utility mod for SMP servers on Modrinth and other Minecraft projects written as Fire Client. This site, fireclient.net, is the launcher and client described on this page. If the address is not fireclient.net, it is a different project. Read what the FireClient mod is.
