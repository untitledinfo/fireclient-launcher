Install FireClient on Windows in five steps

Download the installer, check its SHA-256, run it, sign in and launch Minecraft 1.21.1 Fabric to get the in-game menu.

On this page
  1. 1. Download the installer
  2. 2. Verify the SHA-256 (optional)
  3. 3. Run the installer
  4. 4. Sign in
  5. 5. Play 1.21.1 Fabric
  6. Will an update delete my worlds?
Free tool: Download verifier (check a file's sha-256 in your browser).

FireClient is a free launcher and Fabric client for Minecraft Java Edition on Windows 10 and 11 (64-bit). The installer sets up the launcher; you need your own Minecraft Java Edition account to play online.

1. Download the installer#

Get the installer from the Download section. Wait for the file to finish before you open it.

2. Verify the SHA-256 (optional)#

The current beta installer is unsigned, so Windows may show a security prompt. To check that your file is the one we published, compare its hash with the SHA-256 on the download page. In PowerShell:

Get-FileHash .\FireClient-Setup.exe -Algorithm SHA256

3. Run the installer#

Accept the terms and allow the Windows prompt if you trust the source. Read the Terms and Privacy notice first if you have not.

4. Sign in#

Sign in with Microsoft, or use an offline profile.

5. Play 1.21.1 Fabric#

Launch Minecraft 1.21.1 on Fabric to get the in-game menu on Right Shift. The HUD setup guide shows what to do next.

Will an update delete my worlds?#

No. The installer and uninstaller leave your game-data folder in place, including worlds and resource packs. Back up important worlds before you change game files anyway.
