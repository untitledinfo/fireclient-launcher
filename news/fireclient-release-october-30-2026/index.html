Next FireClient Release Arrives October 30#

🔥 The next FireClient release is scheduled for Friday, October 30, 2026, at 8:00 AM Pacific Time.

We're preparing the next release of FireClient, bringing another update to our Minecraft launcher and in-game client. Check back on release day for the available build and its published release notes.

What Is FireClient?#

FireClient combines a Minecraft Java Edition launcher with an in-game Fabric client for Minecraft 1.21.1. Current features include a draggable HUD with 11 elements, three accent themes, a built-in Modrinth mod manager, a worlds library, memory controls and local skins.

The exact changes included in this release will be listed in the release notes once they are available. Watch this page for updates rather than relying on unconfirmed feature announcements.

Where to Get FireClient!#

When the release is available, visit the official FireClient download page to find the installer and available release information. You can also check the official GitHub Releases page.

Installing FireClient for the first time? Follow our step-by-step Windows installation guide.

A quick security note: The current early-access installer is unsigned, so Windows may display a security warning. Download only from official FireClient sources, and compare the SHA-256 checksum when one is provided.

Join the FireClient Community#

Thank you to everyone testing FireClient, reporting issues and sharing feedback. Follow our Discord community for announcements, support and further release updates.
