Minecraft video settings generator

Choose how strong your PC is and what you care about, and get settings to start from.

How it works

These values are starting points for Minecraft Java Edition 1.21.1, based on the settings that have the biggest effect on frame rate: render distance, simulation distance, graphics mode, particles and entity distance. Low-end PCs get shorter distances and simpler graphics, high-end PCs get longer distances and fancier visuals. Every PC is different, so turn on an FPS counter, change one setting at a time and keep what works.

Questions

Which setting helps FPS the most?

Render distance usually has the biggest effect, followed by simulation distance, graphics mode and particles.

Do performance mods help?

Fabric performance mods from Modrinth can help a lot. Check that each one lists Minecraft 1.21.1 and Fabric.

Should I turn VSync on?

Leave it off for the lowest input delay and turn it on only if you see screen tearing.
