The client, as you see it in game.

Open the FireClient menu with Right Shift in any 1.21.1 Fabric world. Pick a view to look closer.

FireClient 1.21.1

FireClient menu on the title screen

A dark red title screen with an ember sky, your profile in the corner and a FireClient Menu button that opens the client settings.

HUD settings

Four tabs: HUD, Features, Theme and About. Switch each HUD element on or off, then use Edit HUD Positions to drag them where you want.

Launcher home

Pick your account, version and memory, then press Launch. The sidebar gives you Versions, Mods, Modrinth, Worlds, Host Server, Servers, Screenshots, Console and Performance.

Built around how you play.

Everything here is in the current build. A few things are still planned and listed at the end.

HUD and in-game menu

Press Right Shift to open the menu. Drag HUD elements into place with the HUD editor. Positions, visibility and the sprint toggle are saved to config/fireclient/client.json. Three accent themes are included.

Minecraft 1.21.1 on Fabric, Java 21.

Mods and Modrinth

Discover and install mods, drop in your own jar files, switch installed mods on or off, and install curated packs for Performance, Visuals, Utility and PvP.

Worlds library

Browse local worlds with their own icon, last-saved date and size. Refresh, search and sort.

Memory you control

Choose a memory budget in the launcher. It is passed to Java as the max heap, limited to a safe range.

Your files stay put

The pack library has no delete action, and the installer and uninstaller leave your worlds and resource packs on disk.

Local skins

The launcher keeps an offline skin and the in-game mod applies it as a client-side player texture.

Host a server

Run a Paper server from the launcher. It shows Running once Paper reports ready. Router port forwarding is still up to you.

Other versions

The launcher starts other Minecraft versions too, but the in-game client only exists for 1.21.1 on Fabric.

Planned, not built yet: a crosshair editor and cosmetics.

Install in five steps

  1. Download the installer and wait for it to finish.
  2. Verify the file (optional): run Get-FileHash in PowerShell and compare it with the SHA-256 when one is shown.
  3. Install and accept the terms. Allow the Windows prompt if you trust the source.
  4. Sign in with Microsoft, or use an offline profile.
  5. Play 1.21.1 Fabric to get the in-game menu on Right Shift.

A free Minecraft client and launcher in one install.

FireClient pairs a Windows launcher for Minecraft Java Edition with a Fabric client mod, so version management and in-game tools live in the same place.

Made for PvP and everyday play

Keep FPS, CPS, keystrokes, armor and effects on screen, drag each one where you want it, and save the layout to a simple config file.

Mods without the hunt

Search Modrinth from the launcher, install curated packs for Performance, Visuals, Utility and PvP, or add your own jars.

Your worlds stay safe

Updates and uninstalls leave your worlds and resource packs on disk, and the pack library has no delete action.

Open the menu anywhere

Press Right Shift in game to open the FireClient menu and change HUD options and the accent theme instantly.

Questions, answered.
