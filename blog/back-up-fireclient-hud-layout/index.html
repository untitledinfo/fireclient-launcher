Back up and reuse your FireClient HUD layout

Your HUD layout lives in one small file. Copy it to keep a backup or to move your setup to another PC.

On this page
  1. Where the layout is stored
  2. Back it up
  3. Reuse it on another PC
  4. When something looks wrong
  5. Before you share the file

Your HUD layout takes a few minutes to set up, so it is worth backing up. FireClient keeps it in one small file.

Where the layout is stored

Positions, visibility and the sprint toggle are saved to config/fireclient/client.json. The path is relative to your Minecraft game folder, so look for a config folder inside it, then fireclient.

Back it up

  1. Close Minecraft so the file is not being written.
  2. Copy client.json to a safe place, such as a cloud folder or a USB drive.
  3. Put a date in the copy's name, for example client-2026-10-13.json, so you can keep a few versions.

Reuse it on another PC

Install FireClient on the other PC and run Minecraft 1.21.1 on Fabric once, so the config/fireclient folder exists. Close the game, then put your copy in that folder as client.json. The layout should load the next time you start the game. Keep a copy of the original first in case you want to go back.

When something looks wrong

If elements end up off screen after a resolution change, open the menu with Right Shift and use Edit HUD Positions to drag them back. The HUD setup guide has the full walkthrough.

Before you share the file

The file holds layout settings, but open it in a text editor and check it before you post it anywhere. Never post logs or account files publicly. If you are unsure, ask in the FireClient Discord.
