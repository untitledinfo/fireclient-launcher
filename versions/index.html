Minecraft versions and loaders FireClient works with

Which Minecraft versions the launcher runs on Fabric 1.21.4 to 1.20.1 and Forge 1.20.4 to 1.20.1, and where the FireClient mod is included. Updated October 30, 2026.

FabricForgeLaunch another versionQuestions

At a glance

  • FireClient mod (the in-game menu and HUD): Minecraft 1.21.1 on Fabric.
  • The launcher installs and launches Vanilla, Fabric and Forge versions. The tables below show which ones we have tested.
  • Windows 10 and 11 (64-bit) only for now. Download FireClient.

“Launches (tested)” is based on the maintainer's launcher usage history in 30, 2026. “Not tested yet” means we have not checked it, not that it fails. Loader builds come from Fabric and Forge, so availability can change.

Launch another version

  1. Open Versions in the launcher sidebar.
  2. Install a version with Vanilla, Fabric or Forge and choose the Minecraft version.
  3. Press Play next to the installed version.

Not sure which loader you need? Read Fabric vs Forge vs NeoForge vs Quilt, or see what the FireClient mod is.

Questions about versions

Does the FireClient mod work on Minecraft 1.20.1 or 1.21.4?

No. The FireClient mod, which adds the in-game menu and HUD, is built for Minecraft 1.21.1 on Fabric. You can still launch other versions from the launcher without it.

Can I use Forge with FireClient?

The launcher can install and launch Forge versions. We have tested Forge 1.20.1 so far; Forge 1.20.2 to 1.20.4 are not tested yet. The FireClient mod is not available for Forge.

How do I tell you which version works for me?

Say which loader and Minecraft version you tried in the FireClient Discord. Confirmed versions are added to this page.
