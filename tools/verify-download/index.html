FireClient/Tools/Download verifier

Verify a download

Pick a file, paste the published SHA-256 and see if they match. The file never leaves your computer.

How it works

A SHA-256 hash is a fingerprint of a file. This page calculates the fingerprint of the file you choose in your browser, in pieces so large files work and you can cancel, and compares it with the one you paste. If they match, your copy is identical to the file the hash was published for, so it was not changed after publishing. A match does not prove a file is free of malware, and it is only as trustworthy as the source of the hash, so download only from official sources. The button looks up the SHA-256 that GitHub lists for the latest FireClient release, when one is published.

Questions

Is my file uploaded?

No. The hash is calculated in your browser and the file is never uploaded. The only request the page makes is the optional lookup of the latest release hash from this site or GitHub.

Can I do this without the website?

Yes. In PowerShell run Get-FileHash .\FireClient-Setup.exe -Algorithm SHA256 and compare the result.

The hashes do not match. What now?

Do not run the file. Delete it and download again from the official download page.
