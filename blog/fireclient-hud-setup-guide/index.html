How to set up the FireClient HUD in Minecraft 1.21.1

Open the FireClient menu with Right Shift, switch on the HUD elements you want and drag them into place with the HUD editor.

FireClient adds a HUD and an in-game menu to Minecraft 1.21.1 on Fabric. This guide covers how to open the menu, turn elements on, move them, and where your layout is saved.

Open the menu#

Start a Minecraft 1.21.1 Fabric world and press Right Shift. You can also use the FireClient Menu button on the title screen. The menu has four tabs: HUD, Features, Theme and About.

Choose your HUD elements#

The HUD tab has a switch for each element. FireClient includes eleven:

  • Watermark
  • FPS
  • Coordinates
  • Ping
  • Direction
  • Memory
  • Clock
  • Keystrokes
  • Armor
  • Effects
  • CPS

Turn on only what you read during play. A short list keeps the screen clear, whether you are in a PvP match or building.

Move things with the HUD editor#

Press Edit HUD Positions and drag each element where you want it. Positions, visibility and the sprint toggle are saved to config/fireclient/client.json, so your layout is the same the next time you launch.

Pick an accent theme#

The Theme tab has three accent themes. You can switch at any time, and the change shows up in the menu and HUD right away.

Keep the layout tidy#

Start with three or four elements and add more only if you miss them. Leave the middle of the screen clear so the HUD never covers what you are aiming at. If elements end up off screen after you change resolution, open the menu with Right Shift and use Edit HUD Positions to drag them back.

If the menu does not open#

The FireClient menu only exists in the in-game client, which is built for Minecraft 1.21.1 on Fabric with Java 21. Check that you launched that version, because the launcher can start other versions but they run without the FireClient mod. You can also use the FireClient Menu button on the title screen. If the game crashes on start, see the Fabric crash checklist, and if Java is the problem, install Java 21.

What you need#

The in-game client is built for Minecraft 1.21.1 on Fabric with Java 21. The launcher can start other versions, but they launch without the FireClient mod.
