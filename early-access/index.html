FireClient early access

A free Minecraft Java launcher with a Fabric 1.21.1 in-game client. Use it today, tell us what to fix, and watch the full version take shape.

Download early access

Included today

  • Launcher for Minecraft Java Edition on Windows 10 and 11 (64-bit)
  • Fabric in-game client for Minecraft 1.21.1 (Java 21), menu on Right Shift
  • Draggable HUD with 11 elements, saved to config/fireclient/client.json
  • 3 accent themes
  • Modrinth mod manager, your own jar files, and curated packs for Performance, Visuals, Utility and PvP
  • Worlds library with each world's icon, last-saved date and size
  • Memory setting passed to Java as the max heap, local skins, and Paper server hosting

Known limits

  • The installer is unsigned, so Windows may show a security prompt. Compare the SHA-256 on the download section with your file.
  • The in-game mod exists for Minecraft 1.21.1 on Fabric only.
  • Windows only. macOS and Linux are not available.
  • Crosshair editor and cosmetics are planned and not built yet.

Early access questions.

Is early access free?

Yes. The launcher and the in-game client are free to download and use. You need your own Minecraft Java Edition account to play online.

When is the full version?

It is planned for November 2026. There is no exact release day yet, and plans can change. The date will be announced on this site, in the Discord and in the RSS feed.

Which Minecraft version does the in-game client support?

Minecraft 1.21.1 on Fabric with Java 21. The launcher can start other versions, but they run without the FireClient mod.

Will updates delete my worlds?

No. The installer and uninstaller leave your game-data folder in place, including worlds and resource packs. Back up important worlds anyway.

Where do I report a bug?

In the Discord or as a GitHub issue. Please never post access tokens, account files or unredacted logs in public.
