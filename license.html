2. What we can and cannot say about safety

We do not certify FireClient as malware-free, and this page does not claim an independent security audit. Antivirus results differ between engines and change over time, so a scan result is a snapshot, not a certificate.

  • Unsigned early-access build: The installer does not carry an Authenticode code-signing signature, and FireClient is not a Windows Verified Publisher. Windows SmartScreen may therefore warn about the genuine file. That warning is about missing reputation, not a verdict on the file.
  • Official sources only: Download from this site or the official GitHub releases page. Do not run copies from videos, mirrors or direct messages.
  • Check it yourself: When GitHub lists a SHA-256 for the installer, the download page shows it and the browser checker compares it with your file. A matching hash shows your file is the one that was published; it does not show the file is free of malware. You can also scan it with Windows Security or upload it to VirusTotal and read the results yourself.
  • Bundled software: The maintainers state that the installer does not bundle toolbars, cryptocurrency miners or third-party adware installers. This is the maintainers' own statement; we invite you to check and to report anything that contradicts it.

3. How sign-in data is handled

This section describes how the maintainers say FireClient is designed. It is a description, not an audit result.

  • Microsoft sign-in: Sign-in goes through Microsoft's and Xbox Live's own endpoints. FireClient does not see or store your Microsoft account password.
  • Local token storage: Refresh tokens saved in accounts.json are encrypted with the Windows Data Protection API (DPAPI) under your Windows user account. DPAPI keeps other Windows users from reading them. It does not protect against malware running as your own user, so keep your PC clean and never share account files.
  • No FireClient server for tokens: The maintainers state that FireClient does not send tokens, auth headers or passwords to any FireClient server or third party. Authentication traffic is meant to go to login.microsoftonline.com and api.minecraftservices.com.
  • Offline profiles: You can use an offline profile without signing in.

4. Your worlds and files

  • Non-destructive updates: Updates and the uninstaller leave your Minecraft worlds and resource packs on disk, and the resource pack library has no delete action. Back up worlds you care about before changing game files anyway.
