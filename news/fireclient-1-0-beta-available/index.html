FireClient 1.0 is available as a free Windows beta

The launcher and the Fabric in-game client for Minecraft 1.21.1 are free to download for Windows 10 and 11.

On this page
  1. What is in 1.0
  2. Known issues
  3. Planned

FireClient 1.0 is available as a free beta for Windows 10 and 11. It pairs a launcher for Minecraft Java Edition with a Fabric in-game client for Minecraft 1.21.1.

What is in 1.0

  • The launcher memory setting is passed to Java as the max heap, limited to a safe range.
  • The saves library shows each world's own icon, last-saved date and size.
  • The resource pack library has no delete action. Packs and worlds stay on disk through updates and uninstall.
  • The in-game client has a draggable HUD with eleven elements and three accent themes.

Known issues

  • The installer is unsigned, so Windows may show a security prompt.
  • The in-game mod is built for Minecraft 1.21.1 on Fabric only. Other versions launch without it.

Planned

A crosshair editor and cosmetics are planned but not built yet.

Download FireClient or read the installation guide. Feedback and bug reports are welcome in the Discord.
