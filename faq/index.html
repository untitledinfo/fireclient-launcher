FireClient FAQ

Short answers about the free Minecraft Java launcher and Fabric client. Each answer links to a longer guide.

What is FireClient?

FireClient is a free Minecraft Java Edition launcher for Windows 10 and 11, with a Fabric in-game client for Minecraft 1.21.1. It adds a draggable HUD, a Modrinth mod manager and a worlds library. Download page

Is FireClient free?

Yes. The launcher and the in-game client are free. You need your own Minecraft Java Edition account to play online. Download FireClient

Is this the same as the FireClient SMP mod on Modrinth?

No. FireClient on fireclient.net is a free Windows launcher with a Fabric in-game client for Minecraft Java Edition. A utility mod with a similar name for SMP servers exists on Modrinth; it is a separate project and is not affiliated with this site. Download FireClient for Windows

Is FireClient safe to download?

Download it only from fireclient.net or the official GitHub releases page, and compare the SHA-256 shown on the download page with your file. The early access installer is unsigned, so Windows may show a warning. How to check your download

Does FireClient work on Bedrock, MCPE, phones or consoles?

No. FireClient is for Minecraft Java Edition on Windows only. Bedrock and MCPE explained

Does it run on Mac or Linux?

Not yet. The launcher is Windows 10 and 11 (64-bit) only for now. Early access details

Which Minecraft version does the in-game client support?

Minecraft 1.21.1 on Fabric with Java 21. Other versions can be launched without the FireClient mod. Install Java 21

Can I use mods with FireClient?

Yes. The launcher has a mod manager with Modrinth browsing, your own jar files and curated packs for Performance, Visuals, Utility and PvP. Install Fabric mods

How do I open the FireClient menu?

Press Right Shift in game. HUD setup guide

Can I move the HUD elements?

Yes. The HUD has 11 elements that you drag where you want them, and 3 accent themes. HUD setup guide

How much RAM should I give Minecraft?

Around 4 GB is a comfortable start for Fabric with performance mods. More is not always faster. RAM guide

Why does Windows show a warning when I install?

The early access installer is unsigned, so SmartScreen can show a prompt for an app it does not recognise. Verify the file before you run it. Launcher not opening fixes

Minecraft crashes on launch. What should I do?

Check that you use Java 21, remove the last mod you added, make sure every mod matches 1.21.1 and Fabric, and read the crash report. Crash checklist

Is FireClient affiliated with Mojang or Microsoft?

No. FireClient is an independent project and is not affiliated with Mojang or Microsoft. Press kit and facts

When is the full version coming?

The full version is planned for November 2026. No exact date has been announced. Roadmap

Does it have a crosshair editor or cosmetics?

Not yet. A crosshair editor and cosmetics are planned but not built. Roadmap

How do I get help or report a bug?

Ask in the FireClient Discord. Never post access tokens, account files or unredacted logs. Download page
