How to install Fabric mods for Minecraft 1.21.1 from Modrinth

Pick the right version, add Fabric API, install one mod at a time, and fix crashes without losing your world.

On this page
  1. What you need
  2. Pick the right file on Modrinth
  3. Install with the FireClient mod manager
  4. Install one at a time
  5. Fix a crash
  6. Protect your worlds

Mods for Minecraft 1.21.1 only work if they match your game version and mod loader. This guide covers the checks that prevent most crashes, and how the FireClient mod manager fits in.

What you need

  • Minecraft Java Edition 1.21.1
  • The Fabric loader for 1.21.1
  • Fabric API, which many mods require

Pick the right file on Modrinth

On a mod page at Modrinth, open the Versions tab and filter by 1.21.1 and Fabric. A file for another Minecraft version or another loader (Forge, NeoForge, Quilt) will not load on your setup. Read the dependencies list on the page and install anything marked required.

Install with the FireClient mod manager

The FireClient launcher has a mods page with Modrinth browsing, your own jar files, and curated packs for Performance, Visuals, Utility and PvP. Use it to add mods to your Minecraft 1.21.1 Fabric profile so the files land in the right folder. Make sure the profile is set to 1.21.1 Fabric before you add anything. See the install guide if you have not set up the launcher yet.

Install one at a time

Add one mod, launch the game, and check that it opens. Then add the next. When something crashes, you know which mod caused it. Installing twenty at once and guessing is the slow way.

Fix a crash

  • Remove the last mod you added and start again
  • Check that every mod lists 1.21.1 and Fabric, and that Fabric API is present
  • Read the crash report for the mod name near the top, and look for a missing dependency
  • Ask in the FireClient Discord and share only the relevant part of the log, never account files or tokens

Protect your worlds

Mods can change how a world is saved. Make a copy of important worlds before you try a large new set of mods. For better frames, pair this with the FPS guide.
