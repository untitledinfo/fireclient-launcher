Quick facts

Name
FireClient
What it is
Free Minecraft Java Edition launcher plus a Fabric in-game client
Platform
Windows 10 and 11, 64-bit. Not for Bedrock, MCPE, phones, consoles, macOS or Linux
In-game client
Minecraft 1.21.1 on Fabric with Java 21
Price
Free. A Minecraft Java Edition account is needed for online play
Status
Early access v1.0. Full version planned for November 2026, no exact date
Not yet built
Crosshair editor and cosmetics (planned)
