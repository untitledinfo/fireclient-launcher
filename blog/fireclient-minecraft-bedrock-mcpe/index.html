Does FireClient work on Minecraft Bedrock, MCPE or mobile?

FireClient is a Windows launcher for Minecraft Java Edition. Here is what that means for Bedrock, MCPE, phones and consoles.

On this page
  1. What FireClient supports today
  2. What it does not support
  3. How to tell which edition you own
  4. Where to go next

Short answer: no. FireClient is a launcher and Fabric client for Minecraft Java Edition on Windows 10 and 11 (64-bit). It does not work with Minecraft Bedrock Edition, Minecraft Pocket Edition (MCPE), Minecraft on phones or tablets, or consoles.

What FireClient supports today

  • Minecraft Java Edition on Windows 10 and 11
  • The in-game client (HUD and menu) for Minecraft 1.21.1 on Fabric with Java 21
  • Other Java versions can be launched, but they run without the FireClient mod

What it does not support

  • Bedrock Edition on Windows, Xbox, PlayStation or Switch
  • MCPE and Minecraft on Android or iOS
  • macOS and Linux (the launcher is Windows only for now)

How to tell which edition you own

Java Edition starts from the Minecraft Launcher and has a "Java" title. Bedrock Edition on Windows starts from the Microsoft Store app. If you bought Minecraft for Windows from the Microsoft Store as a single "Bedrock" game, check your Microsoft account for Java Edition as well, because many accounts include both.

Where to go next

If you play Java Edition on a Windows PC, start with the install guide or the download page. For Bedrock or mobile, you need a different tool. We would rather say so than send you to an installer that will not work for you. Current limits are listed on the early access page.
