Windows용 FireClient 다운로드

마인크래프트 자바 에디션용 무료 런처입니다. 1.21.1용 Fabric 클라이언트, 이동 가능한 HUD, Modrinth 모드 관리자, 월드 라이브러리를 제공합니다. Windows 10 및 11(64비트)용 얼리 액세스 v1.0.

얼리 액세스 다운로드

Windows용 무료 설치 프로그램 v1.0. 온라인 플레이에는 본인의 마인크래프트 자바 에디션 계정이 필요합니다.

Windows용 얼리 액세스 다운로드

FireClient를 다운로드해 주셔서 감사합니다. 설치 프로그램을 실행하세요. 도움이 필요하면 Discord에 참여하세요.

직접 링크: GitHub Releases의 FireClient-Setup.exe. Windows 10 또는 11, 64비트.

얼리 액세스 설치 프로그램은 서명되지 않아 Windows가 경고를 표시할 수 있습니다. 이 페이지 또는 공식 GitHub 저장소에서만 다운로드하세요.

요구 사항 및 제한

자주 묻는 질문

FireClient는 무료인가요?

네. 런처와 게임 내 클라이언트는 무료입니다. 온라인 플레이에는 본인의 마인크래프트 자바 에디션 계정이 필요합니다.

Minecraft Bedrock, MCPE, Mac, Linux에서 작동하나요?

아니요. FireClient는 Windows의 마인크래프트 자바 에디션 전용입니다.

Windows가 왜 경고를 표시하나요?

얼리 액세스 설치 프로그램은 서명되지 않아 SmartScreen이 메시지를 표시할 수 있습니다. 파일은 이 페이지 또는 공식 GitHub 릴리스에서만 다운로드하고, 확실히 하려면 SHA-256을 비교하세요.

게임 내 클라이언트는 어떤 마인크래프트 버전을 지원하나요?

Fabric이 설치된 마인크래프트 1.21.1과 Java 21입니다. 다른 버전은 FireClient 모드 없이 실행할 수 있습니다.
