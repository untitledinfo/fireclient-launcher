FireClient/Tools/Crash report analyzer

Minecraft crash report analyzer

Paste a crash report or log and see the most likely causes, with links to the right fix.

Nothing is uploaded. Remove your Windows user name and any account details from text before you share it anywhere else.

How it works

The analyzer looks for patterns that cause most Fabric crashes: a Java version that is too old, running out of memory, a mod that needs another mod, mixin errors from conflicting or mismatched mods, graphics driver errors, network failures and download problems. It also pulls out the Minecraft and Java versions, the crash description and the first and last Caused by lines. It cannot read your mind, so use it as a pointer, then confirm with the crash checklist. In the standard setup crash reports are in the crash-reports folder inside your game folder.

Questions

Where do I find the crash report?

In the crash-reports folder inside your game folder. The newest file has the latest crash.

Is my crash report uploaded?

No. It is analyzed in your browser and never leaves your computer.

It found nothing. What now?

Work through the crash checklist, test with no mods, or ask in the Discord and share only the relevant lines.
