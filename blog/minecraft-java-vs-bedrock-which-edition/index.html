Minecraft Java vs Bedrock: which edition should you play?

Platforms, mods, servers and cross-play compared in plain language, plus how to tell which edition you own.

On this page
  1. Quick comparison
  2. How to tell which one you own
  3. Which should you pick?
  4. Where FireClient fits

Minecraft comes in two main versions for most players: Java Edition and Bedrock Edition. They share the same core game but differ in platforms, mods, servers and how you launch them. Here is a plain comparison so you can pick the one that fits.

Quick comparison

  • Platforms. Java runs on Windows, macOS and Linux. Bedrock runs on Windows, consoles, phones and tablets.
  • Mods. Java has a large mod scene through loaders such as Fabric and Forge. Bedrock uses add-ons and Marketplace content instead of mods.
  • Servers. Java has a huge community-server scene, including servers built on Paper. Bedrock has its own server ecosystem and featured servers.
  • Cross-play. Bedrock players can usually play with friends across consoles, phones and PC. Java players play with other Java players.
  • Launcher. Java starts from a launcher, which is where tools such as FireClient come in. Bedrock on Windows starts from its own app.

How to tell which one you own

Java Edition starts from the Minecraft Launcher and shows a Java Edition title. Bedrock Edition on Windows starts from the Microsoft Store app. If you bought the PC version, check your Microsoft account, because the PC purchase often includes both editions.

Which should you pick?

Pick Java if you want mods, custom launchers, the classic server scene or a customisable HUD. Pick Bedrock if you play on a console or phone, or want cross-play with friends on other devices. You can own both and switch.

Where FireClient fits

FireClient is for Java Edition on Windows 10 and 11. It does not run on Bedrock, MCPE, phones, consoles, macOS or Linux, as explained in the Bedrock and MCPE guide. If you play Java on a Windows PC, start with the install guide.
