How to host a Minecraft Paper server on Windows

Run a Paper server on your PC for friends: Java 21, the EULA, port forwarding, the firewall and basic safety.

On this page
  1. 1. Check the basics
  2. 2. Start the server once
  3. 3. Join it yourself
  4. 4. Let friends connect from the internet
  5. 5. Keep it private and safe
  6. 6. Protect the world
  7. If friends cannot connect

A Paper server lets you and your friends play together on a world you control. This guide covers hosting one on a Windows PC for Minecraft 1.21.1. FireClient can run a Paper server from the launcher and shows Running once Paper reports ready, but router port forwarding is still up to you.

1. Check the basics#

You need Java 21 (see the Java 21 guide), enough free memory for the server plus the game, and a PC that stays on while friends play.

2. Start the server once#

Start the Paper server from your launcher or by running the Paper jar. The first run creates the server files. Minecraft's EULA must be accepted before a server will run. If your launcher does not ask, read the EULA, then open eula.txt in the server folder and set eula=true.

3. Join it yourself#

Start Minecraft 1.21.1 and join localhost. If that works, the server itself is fine.

4. Let friends connect from the internet#

Friends outside your home network need your router to send traffic to your PC.

  • Give your PC a fixed local address in your router settings
  • Forward TCP port 25565 to that address
  • Allow Java through Windows Firewall when Windows asks
  • Share your public IP address only with people you trust

If your internet provider shares one public address between many customers (CGNAT), port forwarding will not work. Ask your provider or use a hosting service instead.

5. Keep it private and safe#

  • Keep online-mode=true in server.properties, so only real accounts can join
  • Turn on the whitelist with white-list=true, then add friends with /whitelist add name
  • Keep Paper updated and install only plugins you trust
  • Do not expose admin or remote-control ports to the internet

6. Protect the world#

Back up your world before changing plugins or versions. Lower the view distance in server.properties if the PC struggles, and see the FPS guide for game-side tips.

If friends cannot connect#

Use the connection timed out checklist. Ask for help in the FireClient Discord and never post your router login or account tokens.
