Check your download

  • The download panel above shows the installer's SHA-256 when GitHub publishes one. In PowerShell run Get-FileHash .FireClient-Setup.exe -Algorithm SHA256 and compare the result, or check the file in your browser.
  • Check the signature: in PowerShell run Get-AuthenticodeSignature .\FireClient-Setup.exe | Format-List Status, SignerCertificate. NotSigned means no signature yet, Valid means a certificate Windows trusts, and a self-signed certificate reports an untrusted root. How to read the result.
  • When a release has a verification report attached, the download panel above links to it. Read it yourself; a report is the maintainers' own record, not an independent certification.
  • FireClient is not yet a Windows Verified Publisher, so Windows may still show a warning even for the genuine file. Download only from this page or the official releases.

Download questions.

Is FireClient free to download?

Yes. The launcher and in-game client are free. You need your own Minecraft Java Edition account to play online.

Which Windows versions are supported?

Windows 10 and Windows 11, 64-bit.

Does FireClient work on Bedrock, MCPE, Mac or Linux?

No. It is for Minecraft Java Edition on Windows only.

Why does Windows show a warning?

The early access installer is unsigned, so SmartScreen can show a prompt. Download only from this site or the official GitHub releases page and compare the SHA-256 if you want to be sure.

Which Minecraft version has the in-game client?

Minecraft 1.21.1 on Fabric with Java 21. Other versions can be launched without the FireClient mod.
