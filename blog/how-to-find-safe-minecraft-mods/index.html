How to find safe Minecraft mods (and avoid fake ones)

A short safety checklist for Minecraft mod downloads: trusted sources, version checks and red flags to avoid.

  2. 2. Remember what a mod file looks like
  3. 3. Check version and loader
  4. 4. Read the project page
  5. 5. Check the dependencies
  6. 6. Be careful with unknown authors
  7. 7. Test and keep a backup
  8. If something looks wrong

Most Minecraft mods are made by hobbyists in good faith, but fake download pages and bad files do exist. This checklist helps you pick mods that are safer and more likely to work.

1. Use a trusted platform#

Download from a well-known mod platform such as Modrinth rather than a random link from a video description, a chat message or a file-sharing site. The mod manager in FireClient can browse Modrinth directly.

2. Remember what a mod file looks like#

A Fabric mod is a .jar file that goes in your mods folder. A mod is not an installer. If something calls itself a mod but you have to run an .exe, a .bat or a .msi, do not run it.

3. Check version and loader#

Open the Versions tab and filter for Minecraft 1.21.1 and Fabric. The mods guide shows how. A wrong version is the most common reason for a crash.

4. Read the project page#

Look for a clear description, a source code link, an issue tracker, recent updates and a reasonable number of downloads. A page with no description, copied text or only a download button is a warning sign.

5. Check the dependencies#

Many mods need Fabric API or another mod. Install only the required ones the page lists.

6. Be careful with unknown authors#

For a new or unknown author, read comments and issues and start with well-known mods first.

7. Test and keep a backup#

Add one mod at a time and back up your worlds before big changes. If the game crashes, use the crash checklist.

If something looks wrong#

If you ran a file you now doubt, run a scan with Windows Security, change your Microsoft account password and review your account activity. Never share access tokens or account files with anyone.
