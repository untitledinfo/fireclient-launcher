Minecraft launcher not opening on Windows? Try these fixes

Safe steps for a launcher that does nothing when you click it, from stuck processes to SmartScreen and reinstalling.

  2. 2. End a stuck process
  3. 3. Check that the file is not blocked

Free tool: Download verifier (check a file's sha-256 in your browser).

If a launcher does nothing when you open it, the cause is usually a stuck process, a blocked file or a damaged install. These steps are safe to try in order, and they apply to most Windows launchers, including FireClient.

1. Restart and try again#

Close the launcher, restart your PC and open it once. A leftover background process from an earlier crash is a common cause.

2. End a stuck process#

Press Ctrl + Shift + Esc to open Task Manager. If you see the launcher listed, right-click it and choose End task, then open it again.

3. Check that the file is not blocked#

Right-click the installer or the launcher file, choose Properties and look for an Unblock checkbox near the bottom of the General tab. Tick it and press OK. Only do this for a file you downloaded from an official source, and verify it first with the steps in the safety guide.

4. Look at SmartScreen and antivirus#

Windows SmartScreen or your antivirus can stop an unsigned installer from running. The FireClient early access installer is unsigned, so a prompt is expected. If you have verified the SHA-256 and downloaded from the official page, you can choose to run it. If you are not sure, do not run it.

5. Check your system#

FireClient needs Windows 10 or 11 (64-bit). Make sure Windows is up to date and you have free disk space.

6. Reinstall cleanly#

Uninstall the launcher in Windows Settings, restart, download a fresh copy from the official download page and install again. Your worlds are not stored in the installer folder, but back up your worlds first to be safe.

7. Ask for help#

If it still fails, ask in the FireClient Discord. Say your Windows version and what happens when you click. Never post account files or access tokens.
