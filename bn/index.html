উইন্ডোজের জন্য FireClient ডাউনলোড করুন

মাইনক্রাফট জাভা এডিশনের জন্য বিনামূল্যে লঞ্চার, যাতে আছে 1.21.1-এর জন্য Fabric ক্লায়েন্ট, সরানোর উপযোগী HUD, Modrinth মড ম্যানেজার ও ওয়ার্ল্ড লাইব্রেরি। উইন্ডোজ ১০ ও ১১ (৬৪-বিট)-এর জন্য আর্লি অ্যাক্সেস v1.0।

আর্লি অ্যাক্সেস ডাউনলোড করুন।

উইন্ডোজের জন্য বিনামূল্যে ইনস্টলার, v1.0। অনলাইনে খেলতে আপনার নিজের মাইনক্রাফট জাভা এডিশন অ্যাকাউন্ট লাগবে।

উইন্ডোজের জন্য আর্লি অ্যাক্সেস ডাউনলোড করুন

FireClient ডাউনলোড করার জন্য ধন্যবাদ। ইনস্টলার চালান, সাহায্য লাগলে Discord-এ যোগ দিন।

সরাসরি লিংক: GitHub Releases থেকে FireClient-Setup.exe। উইন্ডোজ ১০ বা ১১, ৬৪-বিট।

আর্লি অ্যাক্সেস ইনস্টলার স্বাক্ষরিত নয়, তাই উইন্ডোজ সতর্কবার্তা দেখাতে পারে। শুধু এই পেজ বা অফিশিয়াল GitHub রিপোজিটরি থেকে ডাউনলোড করুন।

সাধারণ প্রশ্ন।

FireClient কি বিনামূল্যে?

হ্যাঁ। লঞ্চার ও গেমের ভেতরের ক্লায়েন্ট বিনামূল্যে। অনলাইনে খেলতে আপনার নিজের মাইনক্রাফট জাভা এডিশন অ্যাকাউন্ট লাগবে।

এটা কি Minecraft Bedrock, MCPE, Mac বা Linux-এ চলে?

না। FireClient শুধু উইন্ডোজে মাইনক্রাফট জাভা এডিশনের জন্য।

উইন্ডোজ কেন সতর্কবার্তা দেখায়?

আর্লি অ্যাক্সেস ইনস্টলার স্বাক্ষরিত নয়, তাই SmartScreen বার্তা দেখাতে পারে। ফাইলটি শুধু এই পেজ বা অফিশিয়াল GitHub রিলিজ থেকে ডাউনলোড করুন, নিশ্চিত হতে চাইলে SHA-256 মিলিয়ে দেখুন।

গেমের ভেতরের ক্লায়েন্ট কোন মাইনক্রাফট ভার্সন সমর্থন করে?

Fabric ও Java 21 সহ মাইনক্রাফট 1.21.1। অন্য ভার্সন FireClient মড ছাড়া চালানো যায়।
